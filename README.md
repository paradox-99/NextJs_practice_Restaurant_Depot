# Restaurant Depot

Restaurant Depot is a modern Next.js practice project for showcasing food listings, restaurant-inspired content, and user reviews in a clean and polished interface.

## Features

- Responsive landing page with an attractive hero layout
- Food exploration section with card-based content
- Reviews page for browsing customer feedback
- Built with Next.js, React, TypeScript, and Tailwind CSS

## Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- ESLint

## Live Link

> https://next-js-practice-restaurant-depot.vercel.app/

## Getting Started

1. Install dependencies:

```bash
npm install
```

2. Start the development server:

```bash
npm run dev
```

3. Open your browser at:

```text
http://localhost:3000
```

## Available Scripts

```bash
npm run dev
npm run build
npm run start
npm run lint
```
